# AI Engineering Assistant

AI Engineering Assistant is a full-stack platform for repository analysis,
AI-assisted code review, documentation generation, test generation, and
repository-aware Q&A.

## Repository Structure

```text
ai-engineering-assistant/
├── .agents/             # Generated by hs agents --target codex
├── .codex/              # Codex CLI config and hooks
├── .harness/            # Harness state and specs, mostly gitignored
├── backend/             # Spring Boot + Spring AI
├── frontend/            # React + Vite + TypeScript + Tailwind
├── infra/               # Docker Compose, init SQL, Qdrant/pgvector config
├── docs/                # ADRs, API docs, sequence diagrams
├── prompts/             # Versioned prompt library
├── .gitignore
├── hs.settings.json
└── README.md
```

## Phase 1 Local Run

Backend:

```bash
cd backend
mvn test
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

The backend uses PostgreSQL by default. The `dev` profile uses local H2 under
`backend/data/dev` for quick smoke testing. PostgreSQL runtime configuration:

```text
DATABASE_URL
DATABASE_USERNAME
DATABASE_PASSWORD
JWT_SECRET
JWT_ACCESS_TOKEN_MINUTES
JWT_REFRESH_TOKEN_DAYS
REPOSITORY_STORAGE_DIR
```

Frontend:

```bash
cd frontend
npm install
npm run build
npm run dev
```

Vite proxies `/api` to `http://localhost:8080`.

## Phase 1 API Surface

- `POST /api/v1/auth/register`
- `POST /api/v1/auth/login`
- `POST /api/v1/auth/refresh`
- `POST /api/v1/auth/logout`
- `GET /api/v1/users/me`
- `PUT /api/v1/users/me`
- `PUT /api/v1/users/me/password`
- `GET /api/v1/workspaces`
- `POST /api/v1/workspaces`
- `GET /api/v1/workspaces/{id}`
- `PUT /api/v1/workspaces/{id}`
- `DELETE /api/v1/workspaces/{id}`
- `POST /api/v1/workspaces/{id}/repositories`
- `GET /api/v1/repositories/{id}`
- `GET /api/v1/repositories/{id}/status`
- `DELETE /api/v1/repositories/{id}`

Repository uploads accept ZIP files only. Phase 1 validates and stores upload
metadata, creates immutable version records, and exposes an `INDEXING` boundary
for Phase 2 parser/chunk/embedding work.
